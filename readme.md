  <br/>
  <blockquote>
    <b>Answer:</b> WebSockets provide full-duplex, persistent bidirectional communication over a single TCP connection, allowing real-time instant messaging with minimal HTTP overhead!
  </blockquote>
</details>

<details>
  <summary><b>❓ Q2: What is the main difference between MongoDB and MySQL?</b></summary>
  <br/>
  <blockquote>
    <b>Answer:</b> MySQL is a relational (RDBMS) database with structured schemas and SQL queries, whereas MongoDB is a NoSQL document database storing flexible, unstructured JSON-like BSON documents!
  </blockquote>
</details>

  <summary><b>❓ Q3: How does Streamlit simplify Python web app development for apps like BeFit?</b></summary>
